# Goip_Backuper

Скрипт для автоматического создания резервных копий конфигураций устройств **GoIP** и отправки их в Telegram.

## Описание

Скрипт подключается к веб-интерфейсу каждого устройства GoIP, загружает его конфигурацию (`config.dat`), сохраняет файл в локальной директории и отправляет его в указанный чат Telegram. Все операции логируются, старые бэкапы удаляются автоматически через заданный период хранения.

## Возможности

- Создание бэкапов сразу для нескольких устройств GoIP
- Отправка бэкапов в Telegram-чат
- Ежедневная ротация логов (хранение до 30 дней)
- Автоматическое удаление бэкапов старше 7 дней
- Настройка устройств через YAML-конфиг без изменения кода

## Требования

- Python 3.x
- Библиотеки: `requests`, `pyyaml`, `loguru`

## Установка

```bash
pip install -r requirements.txt
```

## Настройка

1. Создайте бота в Telegram через [@BotFather](https://t.me/BotFather) и получите токен.
2. Узнайте `CHAT_ID` чата, куда будут отправляться бэкапы (например, через метод `getUpdates`).
3. Создайте файл `config.yml` в корне проекта на основе примера:

```bash
cp config.yml.example config.yml
```

4. Заполните `config.yml` своими данными:

```yaml
Goip32:
  host: 192.168.1.100:80   # IP-адрес и порт веб-интерфейса GoIP
  user: admin              # Логин для входа
  password: password       # Пароль для входа

Telegram:
  TOKEN: "ВАШ_ТОКЕН_БОТА"
  CHAT_ID: "ВАШ_CHAT_ID"
```

Устройств GoIP можно добавить произвольное количество: каждый блок с именем, начинающимся на `Goip`, будет обработан скриптом.

## Запуск

```bash
python main.py
```

Запуск через `run.sh` (с активацией виртуального окружения):

```bash
./run.sh
```

## Автоматизация

Для ежедневного запуска по расписанию добавьте задачу в cron, например в 2 часа ночи:

```cron
0 2 * * * /usr/bin/python3 /opt/goip/Goip_Backuper/main.py
```

## Логи

Логи записываются в файлы в директории `./logs` (например, `today.log`) и ротируются раз в день с хранением до 30 дней.

## Структура проекта

```
Goip_Backuper/
├── main.py              # Основной скрипт
├── config.yml           # Конфигурация (не попадает в репозиторий!)
├── config.yml.example   # Пример конфигурации
├── requirements.txt     # Зависимости
├── run.sh               # Скрипт запуска
├── goip_backup/         # Директория с бэкапами (не попадает в репозиторий)
└── logs/                # Директория с логами (не попадает в репозиторий)
```

## Автор

Разработано для автоматизации бэкапов и удобства управления устройствами GoIP.
