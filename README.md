# Goip_Backuper

Скрипт для автоматического создания резервных копий конфигураций устройств **GoIP** и отправки их в Telegram.

## Описание

Скрипт подключается к веб-интерфейсу каждого устройства GoIP, загружает его конфигурацию (`config.dat`), сохраняет файл в локальной директории и отправляет его в указанный чат Telegram. Старые бэкапы удаляются автоматически по истечении периода хранения.

## Возможности

- Бэкап сразу нескольких устройств GoIP
- Отправка бэкапов в Telegram-чат
- Уведомление в Telegram при ошибке бэкапа
- Ежедневная ротация логов (хранение до 30 дней)
- Автоматическое удаление бэкапов старше 7 дней
- Настройка устройств через YAML-конфиг без изменения кода

## Требования

- Python 3.8+
- Зависимости из `requirements.txt`: `requests`, `pyyaml`, `loguru`

## Установка

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

## Настройка

1. Создайте бота в Telegram через [@BotFather](https://t.me/BotFather) и получите токен.
2. Узнайте `CHAT_ID` чата, куда будут отправляться бэкапы (например, через метод `getUpdates`).
3. Создайте файл `config.yml` в корне проекта на основе примера:

```bash
cp config.yml.example config.yml
```

4. Заполните `config.yml` своими данными:

```yaml
Goip32:
  host: 192.168.1.100:80   # IP-адрес и порт веб-интерфейса GoIP
  user: admin              # Логин для входа
  password: password       # Пароль для входа

Telegram:
  TOKEN: "ВАШ_ТОКЕН_БОТА"
  CHAT_ID: "ВАШ_CHAT_ID"
```

Каждый блок с именем, начинающимся на `Goip`, обрабатывается как отдельное устройство, таких блоков может быть произвольное количество.

## Запуск

```bash
python3 main.py
```

Или через `run.sh` (с активацией виртуального окружения, если он есть):

```bash
./run.sh
```

## Автоматизация

Для ежедневного запуска по расписанию добавьте задачу в cron, например в 2 часа ночи:

```cron
0 2 * * * /opt/goip/Goip_Backuper/run.sh
```

## Логи

Логи записываются в директорию `./logs` (например, `today.log`) и ротируются раз в день с хранением до 30 дней.

## Структура проекта

```
Goip_Backuper/
├── main.py              # Основной скрипт
├── config.yml.example   # Пример конфигурации
├── requirements.txt     # Зависимости

```
